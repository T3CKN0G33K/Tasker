
# Tasker (Household Pantry Tracker)

A real-time, cross-device household pantry and inventory tracker. Built to keep families and roommates perfectly synced on what's in stock, what's running low, and what needs to be replenished on the next grocery run.

## ✨ Features
* **Real-Time Synchronization:** Add or consume an item on your phone, and watch it instantly update on the family tablet.
* **Role-Based Access:** Create a household as an "Owner" and generate secure, single-tap deep links to invite "Members".
* **Premium iOS-Inspired UI:** A meticulously designed dark-mode interface featuring dynamic state-driven navigation, fluid animations, and unified component scaling.
* **Smart Stock Tracking:** Never run out of essentials. Instantly see when items like trash bags, coffee, or pet food are running low so whoever goes to the store knows exactly what to buy.
* **Automated OTA Updates:** Built-in over-the-air update engine that automatically pings the GitHub API and downloads new APK releases seamlessly.

## 🛠 Tech Stack
* **UI:** Jetpack Compose (Kotlin)
* **Backend & Database:** Firebase Cloud Firestore (Real-time snapshot listeners)
* **Authentication:** Firebase Email/Password Auth 
* **Architecture:** State-driven Root Coordinator pattern
